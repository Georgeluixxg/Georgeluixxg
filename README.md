## 🥗 Veksaya — [veksaya.com](https://veksaya.com)

Aplicación web de recetas y organización de comidas, en producción y hecha entera por mí desde julio de 2024.

- **1.250 recetas** con cálculo nutricional, alérgenos, dietas y raciones que se ajustan solas.
- Lista de la compra, calendario de comidas, despensa, modo cocina paso a paso y comunidad.
- Cuentas con correo, Google y doble factor (TOTP), y suscripciones de pago.

**Tecnología**

| Parte | Herramientas |
|---|---|
| Web | Next.js 16 (App Router, Server Components), React 19, TypeScript, Tailwind CSS 4 |
| Datos | PostgreSQL en Supabase, Row Level Security, migraciones SQL propias |
| Calidad | 732 pruebas de navegador con Playwright (Chromium y WebKit), accesibilidad con axe-core y más de 90 comprobaciones automáticas propias |
| Despliegue | GitHub Actions (tipos, pruebas, build y auditoría en cada cambio), Vercel y Cloudflare |
| Privacidad | Pensada para el RGPD: consentimientos, exportar y borrar los datos de la cuenta |
